Hex Assembly

I've been inspired by the design of Logic Bombs. I need to find a way to articulate my thoughts on that game and those sorts of games. Because there is an aspect of the design that I find so engaging and mentally stimulating. It goes beyond games and taps into a genius part of our mind. It's only in these games that I consciously acknowledge it. To explain it poorly: as I play the game I have an understanding of what options of play are available to me (logical facts). Then I run into a problem which I am incapable of solving based on my limited understanding. My mind intuitively begins finding new options (new logical facts) about the game in order to overcome the problem. Once that new option is found, it is permanently added to my understanding. But the option was always there; I just didn't know it yet. Now I forever know it. Hopefully that poor explanation captures my fascination with logic puzzles: they force your mind to partake in logical discovery.

Anyways, the game idea: a while ago I tried to make a hex-based Picross game, but I gave up on it. Partly because it seemed too derivative. But with this game I'm realizing that there is so much more that can be done with this genre than simply tweaking Picross. I've been brainstorming ideas around programming themed logic puzzles.

K-Map

I feel like there is some way to make a game of optimization. Karnaugh Maps are used to optimize binary algebraic equations. They are close in concept to logic puzzles, but they lack logical depth. There is no domino effect of logic in K-maps. By that I mean, a K-map's solution is not reliant on cascading deduction.

An idea is to give the player the grouping of the k-map without the outputs. Then the player could solve based on the groupings and perimeter values which show the total of the outputs. Still, this does not allow for more deduction.

Idea - Circuitry

The player connects and blocks circuitry components on a breadboard to change an output hex value. Perimeter values represent how many circuits need to be placed. The hex value will match the outputs of a k-map. Once the breadboard is solved, an animation plays solving the k-map and the overall system is optimized.
